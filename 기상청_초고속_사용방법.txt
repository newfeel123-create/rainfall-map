현재 사용 중인 프로젝트에 기상청 캐시 우선 초고속 방식을 적용했습니다.

GitHub 저장소에 이 ZIP 내용을 그대로 덮어쓰세요.

추가된 파일
- kma_forecast.json
- scripts/update_kma.py
- .github/workflows/update-kma.yml

동작
1. 이전에 받은 브라우저 캐시가 있으면 즉시 '기상청 연결됨'
2. 캐시가 없으면 kma_forecast.json을 먼저 읽음
3. 뒤에서 최신 기상청 자료를 다시 확인
4. 오늘/내일 예보통보문 버튼은 준비된 데이터를 즉시 사용
5. GitHub Actions가 약 10분마다 kma_forecast.json을 갱신

중요
- GitHub 저장소의 기존 파일 위에 ZIP 내용을 그대로 업로드하면 됩니다.
- .github 폴더도 반드시 함께 올려야 자동 갱신됩니다.
